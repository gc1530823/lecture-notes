# 디자인

강의노트의 화면 설계와 디자인 시스템을 두는 곳입니다. 디자인 원본은 Figma에 있고, 여기에는 프론트가 쓰는 결과물을 둡니다.

- Figma 파일: [강의노트 디자인](https://www.figma.com/design/dX5M9RxMbJg3walupwZiWF)
  - `01 와이어프레임`: 화면 8개 뼈대 + WF 컴포넌트(TopBar, Button, ListItem, PostIt, Chip, BottomBar, NoteLine)
- `tokens.json` (예정): 색·글자·간격·모서리 같은 디자인 토큰. `web/`이 이 값을 그대로 쓴다.

## 작업 순서

1. ✅ 와이어프레임: 화면마다 뼈대 (자료 목록, 자료 상세, 강의(슬라이드·노트), 공부하기, 시험 예상 지도, 용어 사전, 녹음 정리)
2. 디자인 시스템: 색·글자·포스트잇·버튼·카드·탭·시트
3. 실제 디자인 (일러스트 포함)
4. `web/`에서 컴포넌트로 구현하고 서버 API와 연동
