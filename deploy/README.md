# 내 컴퓨터로 서버 켜기 (무료)

나 혼자 · 발표 · 친구들 모두 이 방법 하나로 써요. 돈이 들지 않고, 카드 등록도 필요 없어요.

- 내 컴퓨터가 서버가 되고, **Cloudflare 무료 터널**이 인터넷 주소(`https://….trycloudflare.com`)를 만들어 줘요.
- 친구들은 **초대 코드**로 가입해서 각자 자기 자료만 봐요. 서로의 강의·녹음·필기는 보이지 않아요.
- 녹음·필기·강의자료는 내 컴퓨터의 `server/data/` 에 저장돼요. 서버를 껐다 켜도 그대로예요.

## 처음 한 번

1. GitHub 저장소에서 **Code → Download ZIP** 으로 받아 압축을 풀어요. (git 을 쓴다면 `git clone`)
2. [Groq 키](https://console.groq.com/keys)를 무료로 만들어 둬요. 키는 채팅이나 저장소에 올리지 마세요.
3. 압축을 푼 폴더의 `deploy` 폴더에서:
   - **Windows**: `start-windows.bat` 을 두 번 눌러요. Python·Node.js·FFmpeg·cloudflared 가 없으면 알아서 설치해요.
   - **Mac**: `start-mac.command` 를 두 번 눌러요. ([Homebrew](https://brew.sh) 가 먼저 있어야 해요. "확인되지 않은 개발자"가 뜨면 오른쪽 클릭 → 열기)
4. 처음에 **Groq 키**(입력해도 안 보여요)와 **초대 코드**를 물어봐요. `deploy/.env` 에 저장되고 다음부터는 묻지 않아요.
5. 화면에 주소와 QR 코드가 나오면 켜진 거예요. **창을 닫으면 서버도 꺼져요.**

## 쓰는 법

| 누가 | 어떻게 |
| --- | --- |
| 나 | 폰에 앱(APK)을 깔고, 화면에 나온 주소를 넣어요. 처음이면 **처음이에요** → 초대 코드 · 이름 · 비밀번호. **처음 가입한 사람이 서버 주인**이라 예전에 혼자 쓰던 자료를 가져가요 |
| 친구 | 앱 APK 와 **주소 링크**, **초대 코드**를 카톡으로 보내요. 앱을 깐 폰에서 링크를 누르면 앱으로 바로 열려요 |
| 발표 | 노트북에서 서버를 켜고 폰 앱으로 시연해요. 서버 없이 화면만 보여 줄 때는 데모 페이지도 있어요 |

- **주소가 바뀌어요**: 무료 터널이라 서버를 다시 켤 때마다 주소가 새로 나와요. 새 주소를 다시 보내 주세요. 앱은 연결이 안 되면 "주소 바꾸기"를 띄워요.
- **같은 와이파이에서만** 쓸 때는 `run.py --local` (Windows: `start-windows.bat --local`) 로 켜요. 터널 없이 더 빨라요.
- **한도 없이**: [Ollama](https://ollama.com) 를 깔고 `ollama pull qwen3:4b` 를 해 두면, Groq 무료 한도에 걸릴 때 이 컴퓨터의 AI 가 이어서 해요.
- **노트북이 잠들면** 서버도 멈춰요. 수업 중에는 전원에 꽂고 잠자기를 꺼 두세요.

## 안전

- 초대 코드를 아는 사람만 가입할 수 있어요. 코드를 바꾸려면 `deploy/.env` 의 `INVITE_CODE` 를 고치고 다시 켜요 (이미 가입한 사람은 그대로).
- 비밀번호는 암호화(scrypt)해서 저장하고, 비밀번호를 10번 틀리면 10분 동안 막혀요.
- `deploy/.env` 와 `server/data/` 는 저장소에 올라가지 않아요.
